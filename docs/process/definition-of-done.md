# Definition of Done

- Task ID trên PR.
- OpenAPI cập nhật nếu đổi API.
- Không `double` cho tiền; có test nếu đụng số dư/transfer.
- Không hex/string hardcode trên UI.
- Layer đúng (Flutter domain sạch).
- Log không PII.
- `flutter analyze` / API tests / admin lint xanh với phần đụng tới.
- Docs/backlog status cập nhật nếu xong task.
