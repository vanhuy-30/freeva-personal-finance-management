# Phụ thuộc module

| Năng lực sau | Phụ thuộc trước |
|---|---|
| Báo cáo | Ví, giao dịch, danh mục, chất lượng dữ liệu |
| Ngân sách | Giao dịch, danh mục, kỳ tài chính |
| Hóa đơn / lịch / nhắc | Định kỳ, timezone, thông báo |
| Mục tiêu | Ví, giao dịch, lịch sử đóng góp |
| Vay / tiết kiệm | Lịch thanh toán, công thức lãi, thông báo |
| Tài sản / đầu tư | Đa tiền tệ, nguồn giá, mô hình ròng |
| AI / dự báo | Lịch sử sạch, taxonomy ổn, consent |
| Import / ngân hàng | Mapping ví, chống trùng, đối soát, hoàn tác |
| Gia đình | RBAC chi tiết, audit, sync, privacy |
| Subscription | Entitlement, analytics, support, chính sách hạ cấp |
