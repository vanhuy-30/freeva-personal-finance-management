# Module 3 — Tài khoản tài chính và ví

- **Phase:** 1; mở rộng Phase 4 (tài khoản đầu tư)
- **Prefix:** `BE`, `MOB`

Tiền mặt, ngân hàng, ví điện tử, thẻ tín dụng. Số dư ban đầu, tiền tệ theo ví. Hạn mức / ngày chốt / thanh toán thẻ. Ẩn/lưu trữ, sắp xếp. Tổng tài sản, tổng nợ, đối soát thủ công (Should).

Không tính trùng ví tiền với tài sản Module 12.
