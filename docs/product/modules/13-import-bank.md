# Module 13 — Nhập liệu và kết nối ngân hàng

- **Phase:** 3 (CSV), 6 (API đối tác), 8 (OCR)
- **Prefix:** `BE`, `MOB`, `SEC`

Phase 3 (`Gate: v1`): nhập CSV/Excel từ app khác và xuất CSV (`BE-P3-011`, `BE-P3-010`). Sao kê ngân hàng Excel/PDF: không làm (chủ dự án chốt 2026-11-11). OCR hóa đơn + user xác nhận: Phase 8 (`BE-P8-E01`), sau khi chốt hướng AI.

Phase 6: API đối tác hợp pháp, sync số dư/GD, revoke token, đối soát. Không ghi đè dữ liệu thủ công không dấu vết.

Won't MVP: kết nối ngân hàng trực tiếp.
