# Task IDs

Format: `{PREFIX}-P{phase}-{nnn}` — `BE-P0-001`, `MOB-P1-014`.

| Prefix | Area |
|---|---|
| BE | Backend API |
| MOB | Mobile Flutter |
| WA | Web admin |
| INF | Infra / CI / env |
| DOC | Documentation |
| SEC | Security & privacy |
| DS | Design system |
| QA | Test / money quality |
| SHD | Shared packages / OpenAPI |
| PRD | Product / research / legal |

Status: `todo` | `doing` | `blocked` | `done`.

PR và commit body phải chứa ID. Issue GitHub chọn prefix + phase + module.
