# Backlog Freeva

Mọi công việc có ID `{PREFIX}-P{phase}-{nnn}`. Prefix: `BE` `MOB` `WA` `INF` `DOC` `SEC` `DS` `QA` `SHD` `PRD`.

- Status: `todo` | `doing` | `blocked` | `done`
- Commit/PR: `feat(MOB-P1-004): …`
- Phase 0–1: task nhỏ. Phase 2–7: epic có DoD, chưa băm ticket triển khai trước khi phase trước đạt gate.
- `Gate: v1` là điều kiện product v1 theo spec, dù ID nằm ở phase sau. Xem [spec-alignment.md](../docs/product/spec-alignment.md).
- Mục lục: [index.md](index.md)

### PREFIX-P0-000 — Tiêu đề
